# 🚀 SEVA AI – AI Powered Volunteer Platform 

### Smart Volunteer Coordination using AI, Real-Time Data & Automation

SEVA AI is a web-based platform that connects NGOs and volunteers in real-time by identifying urgent needs, prioritizing them using AI logic, and enabling quick volunteer assignment.

---

## 🎯 Problem Statement

During disasters and social crises in India, coordination between NGOs and volunteers is inefficient.

- NGOs struggle to find volunteers quickly  
- Volunteers are unaware of real-time needs  
- Data is often collected manually and scattered  
- No centralized system for coordination  

👉 This leads to delayed response and reduced impact.

---

## 💡 Solution

SEVA AI provides a centralized platform where:

- NGOs can post real-time needs  
- Needs are displayed on a live map  
- AI calculates priority based on urgency & reports  
- Volunteers get smart task suggestions  
- Tasks can be accepted instantly  
- Details are shared via WhatsApp  

---

## ✨ Key Features

- 🔐 User Authentication (Volunteer / NGO roles)  
- 📝 Real-Time Need Posting  
- 🗺️ Live Needs Heatmap (India)  
- 🤖 AI-Based Priority Scoring  
- 🎯 Smart Volunteer Matcher  
- 📸 OCR Simulation (Gemini AI concept)  
- 📊 AI Insights (Priority & Allocation)  
- 📱 WhatsApp Integration  
- 📍 Google Maps Location Sharing  
- ⚡ One-Click Task Acceptance  

---

## 🧠 AI Functionality

- Priority calculation based on urgency and reports  
- Smart matching score for volunteers  
- AI insights for better resource allocation  
- OCR-based need generation (simulated for prototype)  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, Tailwind CSS, JavaScript  
- **Maps:** Leaflet.js + OpenStreetMap  
- **AI Logic:** Custom JS-based scoring + Gemini concept  
- **APIs:** WhatsApp Web, Google Maps  
- **Deployment:** Can be hosted on Vercel / Netlify  

---

## 🖥️ MVP Features (Implemented)

- Login system with role selection  
- Dashboard with live statistics  
- Interactive map with urgency markers  
- Dynamic need cards  
- Smart volunteer matcher  
- OCR upload simulation  
- AI insights generation  
- WhatsApp task sharing  

---

## 🚀 How It Works

1. User logs in as Volunteer or NGO  
2. Needs are displayed on dashboard and map  
3. AI calculates priority score  
4. Volunteers view and get matched with needs  
5. Volunteer accepts task  
6. Task details sent via WhatsApp  
7. Assignment tracked in system
